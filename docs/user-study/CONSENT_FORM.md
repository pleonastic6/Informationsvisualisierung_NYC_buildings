# Einverstaendniserklaerung

## Zweck

Im Rahmen einer Studienarbeit zur Informationsvisualisierung wird eine Nutzertest-Session mit begleitender EEG-Aufzeichnung durchgefuehrt.

## Erhobene Daten

- Interaktionen mit dem Prototyp
- Beobachtungen waehrend des Tests
- ggf. Audio/Notizen des Moderators
- EEG-Messdaten waehrend der Bearbeitung

## Verwendung

Die Daten werden ausschliesslich fuer die Lehrveranstaltung und die zugehoerige Studienarbeit verwendet.

## Datenschutz

- personenbezogene Daten werden nur im noetigen Umfang erhoben
- Ergebnisse werden nach Moeglichkeit anonymisiert oder pseudonymisiert ausgewertet
- keine Weitergabe ausserhalb des Studienkontexts

## Freiwilligkeit

Die Teilnahme ist freiwillig. Ein Abbruch ist jederzeit ohne Nachteile moeglich.
